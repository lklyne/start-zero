# TanStack Zero Starters

This repository contains TanStack Zero starter templates:

## Available Versions

### start-zero (Main Branch)

- **Framework:** TanStack React Start with Zero Sync
- **Branch:** `main`
- **Description:** Core implementation using TanStack React Start

### start-zero-supabase (Supabase Branch)

- **Framework:** TanStack React Start with Zero Sync + Supabase Auth
- **Branch:** `start-zero-supabase`
- **Description:** Enhanced version with Supabase authentication integration

## Legacy

- `router-zero/` - Original TanStack React Router implementation (not actively maintained)

## Getting Started

1. Clone the repository
2. Switch to your preferred branch:
   - `git checkout main` for the core version
   - `git checkout start-zero-supabase` for the Supabase version
3. Navigate to the `start-zero/` directory
4. Follow the setup instructions in `start-zero/README.md`
